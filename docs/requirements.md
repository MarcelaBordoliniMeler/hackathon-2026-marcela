# Requirements – FP Agentic Mentor

Conceptual requirements for a future prototype.

## Users

- **Learners** in Vocational Education and Training (VET/FP).
- **Teachers** who guide modules and assess competencies.

## Functional requirements

| ID | Requirement |
|---|---|
| F1 | Explain a selected competency in plain language, with examples and evidence criteria. |
| F2 | Propose practical activities aligned with the competency and the learner's level. |
| F3 | Build and update a personalised learning path for a module. |
| F4 | Register each piece of evidence and link it to the competency it demonstrates. |
| F5 | Assemble a structured portfolio that the learner can export and share. |
| F6 | Show progress to the learner and give feedback and reminders. |
| F7 | Let the teacher review, edit or reject any suggestion before it is used. |
| F8 | Clearly label content generated by the AI versus content written or edited by people. |

## Non-functional requirements

| ID | Requirement |
|---|---|
| N1 | **Human-in-the-loop:** no recommendation replaces the teacher's judgement. |
| N2 | **Data minimisation:** request only the information needed for the task. |
| N3 | **Privacy:** learner data stays within the school's environment and policies. |
| N4 | **Accessibility & inclusion:** clear language, adaptable to different learning styles and paces. |
| N5 | **Low cost:** buildable with tools that schools already have. |
| N6 | **Traceability:** every piece of evidence and every approval can be traced. |
